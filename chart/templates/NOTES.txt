{{- if not (and $relay $outbox) }}

  !! DATA LOSS WINDOW OPEN — the #4 lineage durability chain is broken.
     A lineage event is staged to the outbox, published fire-and-forget, then dropped; the relay
     drains whatever a crash left behind. Both halves are ON by default; this install disabled:
{{- if not $outbox }}
       - services.lineage.outbox.enabled=false  -> nothing is staged, so a crash between the Lance
         commit and the publish loses the event, its author and its inputs PERMANENTLY.
{{- end }}
{{- if not $relay }}
       - services.lineage.relay.enabled=false -> nothing drains the outbox, prunes the feed or forwards it.
         A lost event stays lost, and staged events accumulate in s3://{{ $.Values.minio.bucket }}/_lineage_outbox forever.
{{- end }}
     Re-enable with: helm upgrade ... --set services.lineage.outbox.enabled=true --set services.lineage.relay.enabled=true
{{- end }}
{{- end }}
