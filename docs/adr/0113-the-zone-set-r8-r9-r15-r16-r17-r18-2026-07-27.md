# 0113. The zone set (R8, R9, R15, R16, R17, R18, 2026-07-27)

Source: `docs/architecture/lance-ns-merge.md:450-453,464,467` (at `44b354f3`) (owner rulings R8, R9, R15, R16, R17 and R18, all 2026-07-27).

## Context

The merge brought two zone sets together: rask's (home, overview, storage, compute, discover, train, studio)
and lance-ns's (home, lakehouse, media, annotator). Each surviving surface needed one owner zone.

## Decision

- **R8.** rask's browse/viewing/search surfaces go to the media plane
  ([0112](0112-the-media-plane-absorbs-rask-s-discovery-and-viewing-r5-r6.md)); what survives of rask's own
  frontend is **compute** (the Ray dashboard, jobs, actors, cluster views), because that is the plane rask
  owns; rask's `storage` zone folds INTO the lakehouse.
- **R9.** `studio` survives as its own top-navbar zone.
- **R15.** The shell top navbar carries EVERY zone; a zone missing from it is a defect regardless of scaffold
  status.
- **R16** (supersedes R8's overview-into-home). Overview folds into **compute**: it is Ray-plane material.
- **R17** (supersedes R8's train-into-lakehouse). Training returns as its own zone and the model registry
  lives there: submit, watch, monitor, analyse, view and test models.
- **R18.** The lakehouse ships the S3 object browser with blob preview and a table viewer, so R8's storage
  absorption is built, not merely the old zone deleted.

## Consequences

- The zones today are seven: `home`, `lakehouse`, `explorer` (the media plane, renamed), `annotator`,
  `compute`, `models` and `studio` (`frontend/microfrontends/`).
- R17's training zone is `models`, which replaced `train` on train's port; the shell's nav carries Compute,
  Models and Studio entries (`frontend/packages/ui/src/lib/shell/nav-config.ts:613,656,665`).
- R18's storage area lives at `/lakehouse/catalog/storage`, with a tiers view
  (`frontend/microfrontends/lakehouse/src/routes/catalog/storage/tiers`), grouped by the registered store
  roles of [0123](0123-storage-is-registered-with-a-role-r28-2026-07-28.md).
