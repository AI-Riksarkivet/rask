The medallion (now event-driven)

The lance-ray producer + the raw→bronze / bronze→silver / silver→gold movers are event-driven services (services/medallion/): each subscribes to its upstream trigger over Dapr pub/sub, emits OpenLineage (the DERIVED_FROM edge), and fires the next trigger — one distributed trace raw→gold, with FGA gating per hop. The fake-Ray compute (gated, default off) gives each stage a real in-process Lance write, so the loop produces actual versioned data, not just provenance. Remaining (live kind+Dapr stack): the S3 ObjectCreated input-binding trigger + a Dapr-Workflow gold QC gate, and swapping the fake compute for real distributed lance-ray at the rask merge.
