### 2. OpenFGA model (`SK/governed/auth/model.fga`, 483 lines; tests `model.fga.yaml`, 1143 lines, `model_file: ./model.fga`)

### 3. ratch

- **How it writes**: direct pylance on **local filesystem paths**. `RA/core/dataset.py:73-81` (`lance.write_dataset(..., mode="create", data_storage_version="2.2", enable_stable_row_ids=True)`), `:84-96` append, `:99-114` overwrite (re-applies flags). Driver commits: `RA/core/driver.py:99-103 _table_uri` resolves `Path(db_path)/<table>.lance` absolute, then `lance.dataset(uri)` (:280, :433) with **no `storage_options`**, `ds.add_columns` (:317, :326), `ds.merge_insert(...).execute` (:355). Ingest: `RA/ingest/ingest.py:296-299` (`ds.delete` + `append_rows(..., allow_external_blobs=True)`), `:339`, FTS/BTREE via lancedb `table.create_index` (:420-434). Root CLI option is `db: Path = Path("./transcripts_v2.lance")` (`RA/cli/_app.py:33, 78`) — an `s3://` root cannot even be addressed.

No replay marker (`run_id` is minted per event from `seed=f"{stage.name}-{output_name}-{result.version}"` :164 only inside the unused path). Bypasses the catalog entirely.
- **Pins**: 2.2 + stable row ids pinned at create/overwrite (`dataset.py:36, 77-78, 103-104`); appends inherit. Blob-v2 **thresholds are not set** (no `blob_inline_threshold`/`packed` option anywhere; ingest.py:257-261 relies on Lance's 64 KB default). `allow_external_blob_outside_bases=True` (`ingest.py:297-299`) — external pointers with no registered base, the exact thing `SK/lakehouse/blobs.py:71-77` warns is unrecoverable.
- **Ray path**: `lance_ray.read_lance` for scans (`driver.py:340, 374, 448, 512`) and `lance_ray.create_index`/`create_scalar_index` for distributed index builds (`RA/features/indexing.py:105-139`); writes are driver-side pylance, not `lance_ray.write_lance`. - **Retrieval depends on ungoverned indexes**: `RA/retrieval/search.py:132` does `table.search(query, query_type="fts")`, which requires the Tantivy index built only by ratch's own `ingest_many` (`ingest.py:420-424`) or `ratch pipeline index` (`indexing.py:49-58` standard set: IVF_PQ on `text_embedding`/`frame_embedding`/`caption_embedding`/`embedding`, FTS on `text`/`caption`, BTREE on `doc_id`/`audio_path`). The catalog's only index op is `ensure_merge_key_index` (BTREE on the merge key, `services/catalog/src/catalog/services/dataplane.py:1421`). Nothing governed builds FTS or IVF_PQ.
- **Production-state-changing CLI?** Yes in capability: `ingest`, `materialize-blobs` (overwrite drops indexes, `materialize.py:37-45`), `pipeline run` (add_columns/merge_insert), `pipeline index`, `speaker` (overwrite) all mutate Lance tables; `run_runner` submits Ray jobs (`jobs.py:114-140`, default dashboard `http://127.0.0.1:8265` :70). It ships in the production head image: `.docker/ray-cluster.dockerfile:62-69` runs `uv sync --package ratch`, and `[project.scripts] ratch = "ratch.__main__:main"` (`packages/ratch/pyproject.toml:70`). Mitigation in practice: it can only address local paths, so it cannot hit a governed S3 table; but CLAUDE.md's "No production-state-changing CLIs" and "the one sanctioned CLI exception" are in tension, and modality leaks (`FTS_LANGUAGE = "Swedish"` `indexing.py:23`; `referenskod/namn/bildid/extraid` columns `ingest.py:86`; default caption model `cli/pipeline.py:580`) contradict the agnostic-lakehouse ruling.

### 4. lineage-kit

- **Durability**: fire-and-forget by contract. `ClientEmitter.emit` (`LK/emitter.py:59-63`) wraps `client.emit(...)` in `except Exception: log.warning(...)`; `Emitter` protocol says "must never raise" (:31). Transport is the official **synchronous** `HttpTransport` (verified: `HttpTransport.emit` is not a coroutine, openlineage 1.52.0) with `timeout=5.0` (`LK/config.py:51`) and the client's default urllib3 retry `{total:5, backoff 0.3, status_forcelist 500/502/503/504}` — so an HTTP 2xx **is** awaited on the calling thread, but 401/403/4xx and exhausted retries vanish with one log line. No outbox, no ack from the lineage service beyond the HTTP status. When the lineage service is down: `NoopEmitter` if endpoint unset (:36-40, :71); with endpoint set, ~5 retries × 5 s then a swallowed warning. Same policy as the catalog's `DaprEmitter._send` (`services/catalog/src/catalog/core/lineage_emit.py:652-665`) — both swallow; only medallion's `SK/lakehouse/outbox.py` stages before publishing.
- **Facets**: standard facets are pydantic mirrors of `facet_v2` (`LK/schemas.py:107-202`), asserted equal to the installed client by `tests/test_spec.py:100`. Custom facets are bags: `RunFacets(extra="allow")` (:205-221); `custom_facet(**fields)` stamps `_producer`/`_schemaURL=BaseFacet` (:82-84). The `lance` facet is `{operation, version, token, project}` and `author` is `{name, sub}` — declared only as string constants `LANCE_RUN_FACET`/`AUTHOR_RUN_FACET` in `LK/consume.py:46-49`; **no schema** validates them, so a producer that stamps a role literal in `author.sub` or omits `lance.project` passes silently (the notifications trap CLAUDE.md names).
- **Run-id / replay**: `run_id_for(seed)` = uuid5 under `https://github.com/Borg93/lance-ns` (`LK/runs.py:49, 56-60`), byte-aligned with `SK/openlineage.py:56-59`. But `LineageRun` defaults to `uuid4()` (`runs.py:90`) and `job_run`/`@stage`/`lineage_task` all mint fresh ids unless the caller passes `run_id=` — a redelivered Ray stage produces a second `(:Run)`. Terminal-once guard `_emit_terminal` (:147-167). There is **no replay marker** facet; the only replay key in the estate is the catalog's `run_id` transaction property (`services/ingest/src/ingest/catalog_service.py:236-241`).
- **Auth**: service-door headers sent only when both token and identity are set (`emitter.py:85-93`); half-config logs and sends neither.

### 5. storage and ray-kit

- **Credentials**: static keys only. `ST/client.py:76-90` — endpoint from `RASK_S3_ENDPOINT_URL|S3_ENDPOINT_URL|HCP_ENDPOINT` (:23), keys from explicit args or the boto env chain, `region` from `AWS_REGION` (:87). ### 9. Five most consequential findings

1. **HIGH — ratch is an ungoverned direct write path shipped in the production head image.** Commits via bare pylance on local paths with no FGA, no lineage (draft unused), no replay marker: `RA/core/driver.py:99-103, 280, 317, 355`; `RA/core/dataset.py:73-81`; `RA/lineage.py:1-5`; image `.docker/ray-cluster.dockerfile:62-69`; script `packages/ratch/pyproject.toml:70`. Fix: route ratch commits through `SK/lancekit/writer.CatalogTableWriter` (catalog `merge_insert`/`add_columns` doors) and move the `ratch` console script to a dev-only extra so the head image carries the library, not the CLI.

2. **HIGH — vended credentials cannot pass through any package seam.** `lance_storage_options` (`SK/lakehouse/objectfs.py:21-43`), `s3_filesystem` (:46-57), `records._s3_client` (`records.py:58-71`) and `storage.s3_client` (`ST/client.py:76-90`) all lack `session_token`, while the catalog vendor issues one (`services/catalog/src/catalog/core/vending.py:213, 278`); `catalog/core/config.py:373-381` hand-rolls the dict besides. Fix: add `session_token` to `StorageOptions` and every constructor, and make the catalog build its options through `lance_storage_options`.

3. **HIGH — lineage emission is swallow-on-failure in both kernels, and the catalog has no outbox.** `LK/emitter.py:59-63` and `services/catalog/src/catalog/core/lineage_emit.py:652-665` log and continue; `SK/dapr_publish.py:75-76` has no broker ack; only medallion uses `SK/lakehouse/outbox.py`. Because the cascade is *driven* by the bronze-write event, a swallowed emit silently cancels a run. Fix: give lineage-kit an outbox-backed `Emitter` (stage `RunEvent.to_wire()` under `<outbox>/<run_id>@<type>.json` via `SK/lakehouse/outbox` before transport) and make the catalog's `DaprEmitter` use it.

4. **MEDIUM-HIGH — the FGA model cannot express the verdict's rungs.** No `branch`, `column`, `base`, or `estate` type; `can_create_branch: owner` on `table` (`model.fga:357`) is the whole branch story and branch writes fall through to the table's `can_write_data: writer` (:349); bootstrap is a configured root warehouse (`catalog/core/config.py:231`) plus out-of-band tuples (`SK/governed/fga.py:285-315` writes none); `endpoints/columns.py` has no FGA check. Fix: add `type branch { parent:[table]; writer/reader; can_write_data }`, a column-policy relation, an `estate` root type with `can_create_project`, plus `.fga.yaml` cases and an `_CHILD_EDGE_PARENT_TYPES` entry (`fga.py:126`).

5. **MEDIUM — duplicated seams that will drift.** Commit-conflict classifier twice (`SK/lancekit/writer.py:53` vs `services/catalog/src/catalog/services/dataplane.py:571-595`); two emit kernels with three `PRODUCER`s (`SK/lancekit/openlineage.py:49`, `LK/schemas.py:35`) and services split between them (`lineage/repository.py:77`, `maintenance/core/lineage_emit.py:41`, `medallion/workflow.py:755` on `service_kit.openlineage`; `medallion/schemas/events.py:33` on lineage-kit); ingest hand-maps 409 (`ingest/catalog_service.py:245-248`) instead of `translate_catalog_errors`; `ST/client.py:102` is a verified no-op retry tweak. Fix: delete `SK/lancekit/openlineage.py` + `SK/lancekit/lineage_emit.py` (no service importer) in favour of lineage-kit, export one `commit_conflict()` classifier from `SK/lancekit/writer.py` that the catalog imports, and remove `client.py:102`.
