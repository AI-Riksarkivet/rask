# HEADLINE
Below the catalog's FGA gates, four zero-trust holes are open today: OpenFGA answers unauthenticated calls; every lakehouse pod runs as a `default` ServiceAccount that the Dapr subchart lets read every Secret; NATS authenticates no publisher; and a write-tier vend reaches `_refs/` and `_versions/`, so the tag, restore and version-delete rungs can be bypassed by going straight to the store. Provenance breaks in normal operation in five places: the outbox relay deletes every staged DDL event as poison; the version-delete door removes tagged and current manifests, so version numbers get reused; full-lane stage writes rewrite every row, so the change feed and the delta lane see the whole tier as changed; the in-process fast path drops corrected upstream rows; and an insert's event names whatever version is latest, not the one it committed. The pylance 12 bump is nearly done in the working tree but has one hard blocker — 12 commits fragments whose file version differs from the table's and sets a sticky flag that locks the table out of maintenance and out of every v11 reader, so the commit door must refuse such fragments first — and, on the side question, reading the Lakekeeper chart paid off: it exposed three traps the new rask-helm skill does not cover.
